# 🦖 AR Dinosaur Experience (WebAR)

เว็บ AR วางไดโนเสาร์ 3D ลงบนพื้นจริงผ่านกล้องมือถือ ด้วย HTML + CSS + JavaScript + Three.js + WebXR (hit-test)

## โครงสร้างไฟล์

```
ar-dinosaur/
├── index.html          โครงหน้าเว็บ (หน้าเริ่ม, HUD, ปุ่มควบคุม)
├── css/style.css       UI สไตล์ Jurassic
├── js/
│   ├── main.js         WebXR, hit-test, วางไดโนเสาร์, ปุ่ม, ท่าทางสัมผัส, โหมด Preview
│   ├── dino.js         โมเดล 3D + แอนิเมชัน Idle/Walk/Roar/Turn/Attack (+ ตัวโหลด GLB)
│   └── audio.js        เสียงคำราม/ขู่/ฝีเท้า สังเคราะห์ด้วย Web Audio
├── lib/three/          Three.js (r187) เก็บไว้ในโปรเจกต์ ไม่ต้องพึ่ง CDN
└── models/             (ไม่บังคับ) วางไฟล์ dino.glb ที่นี่
```

## วิธีติดตั้งและเปิดใช้งาน

ไม่ต้อง `npm install` / ไม่ต้อง build — เป็นไฟล์ static ล้วน แต่ **WebXR และกล้องต้องใช้ HTTPS** (ยกเว้น `localhost`)

### วิธีที่ 1 — ทดสอบบนคอมพิวเตอร์ (โหมดดูตัวอย่าง 3D)
```bash
cd ar-dinosaur
python3 -m http.server 8000      # หรือ npx serve .
```
เปิด http://localhost:8000 แล้วกด **ดูตัวอย่าง 3D** เพื่อดูโมเดลและลองปุ่มทั้งหมด

### วิธีที่ 2 — ทดสอบ AR บนมือถือ Android ผ่านสาย USB
1. เปิด Developer options + USB debugging บนมือถือ แล้วต่อสาย
2. รัน server ตามข้างบน แล้วรัน `adb reverse tcp:8000 tcp:8000`
3. เปิด Chrome บนมือถือไปที่ `http://localhost:8000` (ถือเป็น secure context)

### วิธีที่ 3 — เปิดผ่านอินเทอร์เน็ต (HTTPS)
- อัปโหลดทั้งโฟลเดอร์ขึ้น **GitHub Pages / Netlify / Vercel / Cloudflare Pages** (ได้ HTTPS ให้อัตโนมัติ)
- หรือใช้อุโมงค์ชั่วคราว เช่น `npx localtunnel --port 8000` หรือ `cloudflared tunnel --url http://localhost:8000`
- สแกน QR / พิมพ์ URL บนมือถือ

### ข้อกำหนดของอุปกรณ์
| ต้องมี | รายละเอียด |
|---|---|
| มือถือ | Android ที่รองรับ **ARCore** |
| แอป | **Google Play Services for AR** (ติดตั้งจาก Play Store) |
| เบราว์เซอร์ | **Chrome** (หรือ Edge/Samsung Internet รุ่นใหม่) |
| iPhone / iOS Safari | **ยังไม่รองรับ WebXR AR** — เว็บจะแสดงข้อความแจ้งเตือน และเปิดโหมดดูตัวอย่าง 3D ให้แทน |

## วิธีเล่น
1. กด **อนุญาตใช้กล้อง** (ครั้งแรก) → อนุญาต → กด **เริ่ม AR**
2. ขยับมือถือช้าๆ ให้เห็นพื้น จนเห็นวงแหวนสีเหลือง
3. **แตะหน้าจอ** เพื่อวางไดโนเสาร์ (แตะที่อื่นอีกครั้งเพื่อย้าย)
4. ใช้ปุ่มด้านล่าง

| ปุ่ม | หน้าที่ |
|---|---|
| WALK | เดิน (ขยับขา + หาง, เดินวนอยู่ในรัศมีรอบจุดที่วาง) |
| IDLE | หยุดเดิน ยืนหายใจ/หันมองรอบๆ |
| ROAR | อ้าปากคำราม พร้อมเสียงและสั่นเครื่อง |
| ATTACK | พุ่งงับโจมตี |
| ROTATE / ซ้าย | หมุนตัวทีละ 45° (ไดโนเสาร์หันหัวนำ แล้วก้าวขาหมุนตาม) |
| เล็ก / ใหญ่ | ย่อ–ขยายขนาด |
| RESET | เริ่มต้นใหม่ (เอาไดโนเสาร์ออก แล้ววางใหม่) |

ท่าทางสัมผัส: **หนีบ 2 นิ้ว** = ย่อ/ขยาย, **บิด 2 นิ้ว** = หมุนไดโนเสาร์

## ใช้โมเดล GLB ของตัวเอง (ไม่บังคับ)
วางไฟล์ที่ `models/dino.glb` — ระบบจะโหลดแทนโมเดลที่สร้างด้วยโค้ดอัตโนมัติ
- โมเดลควรหันหน้าไปทาง **+Z** (มาตรฐาน glTF) และอยู่แนวตั้งตามแกน Y
- ตั้งชื่อ AnimationClip ให้มีคำว่า `idle`, `walk`, `roar`, `turn`, `attack` (ไม่สนตัวพิมพ์เล็ก/ใหญ่)
  ถ้าไม่มี `turn` จะใช้ `walk` แทน
- ระบบปรับขนาดให้ยาว ~4.5 หน่วยและวางบนพื้นให้เอง

> หมายเหตุ: เส้นทาง GLB เป็นตัวเลือกเสริม ยังไม่ได้ทดสอบกับไฟล์โมเดลจริง ส่วนโมเดลที่สร้างด้วยโค้ดทดสอบแล้ว

## แก้ปัญหาเบื้องต้น
- **ปุ่ม AR กดไม่ได้** → ไม่ใช่ HTTPS / อุปกรณ์ไม่รองรับ ดูข้อความสีแดงบนหน้าเริ่ม
- **ไม่พบพื้นผิว** → เล็งกล้องไปที่พื้นที่มีลายและแสงพอ ขยับมือถือช้าๆ
- **ไม่มีเสียง** → เสียงเริ่มหลังแตะปุ่มครั้งแรก ตรวจว่าไม่ได้ปิดเสียงมือถือ
- **ปฏิเสธสิทธิ์กล้องไปแล้ว** → แตะไอคอนแม่กุญแจข้าง URL → การอนุญาต → เปิดกล้อง
- ใน DevTools จะมี 404 ของ `models/dino.glb` หนึ่งครั้ง — เป็นเรื่องปกติเมื่อไม่ได้วางโมเดลเอง
